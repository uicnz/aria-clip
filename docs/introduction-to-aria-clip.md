Aria Clip is a free browser extension that lets you highlight pages and save web content to your vault.

> [!warning]- Requires Aria 1.7.2 or above
> Clip relies on features added to [[Aria URI]] in Aria 1.7.2. Please make sure you're using Aria 1.7.2 or above.

## Install Clip

Get the Aria Clip extension from the official directory for your browser:

- [Chrome Web Store](https://github.com/uicnz/aria-clip/releases)
 - For Chrome, Brave, Arc, Orion, and other Chromium-based browsers.
- [Firefox Add-Ons](https://github.com/uicnz/aria-clip/releases)
 - For Firefox and Firefox Mobile.
- [Safari Extensions](https://github.com/uicnz/aria-clip/releases)
 - For macOS, iOS, and iPadOS.
- [Edge Add-Ons](https://github.com/uicnz/aria-clip/releases)
 - For Microsoft Edge.

## Privacy

Aria Clip saves content locally to your Aria vault and follows our [privacy policy](https://aria.bot/privacy). Your data is not collected, and we do not gather any usage metrics. The code is [open source](https://github.com/uicnz/aria-clip) and auditable.
